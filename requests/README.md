# Requests

One file per request, numbered in order: `001-add-search.md`, `002-edit-history.md`.

Start every request by copying `000-TEMPLATE.md`. Never delete a request file — completed ones stay as the record of what was asked, what was decided, and who approved it.

The file is the whole story of one request: the original words, every question and answer, the plan, the approval, the test results, and what was actually built.
